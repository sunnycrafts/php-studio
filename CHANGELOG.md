# PHP Studio — Changelog

Internal review · newest first. Semantic version = `version` in package.json.

## 1.4.1 · 2026-07-16 · fix "Cannot find module main.js" on other machines

- Cause: the build shipped with asar disabled, so the portable EXE unpacked
  1,346 loose files (mostly monaco-editor, incl. its unused esm/ tree) into
  %TEMP% on every launch. On a machine where that extraction was interrupted
  or incomplete — antivirus scanning an unsigned exe, a truncated file
  transfer, a stale partial temp dir — Electron started with no
  resources\app\main\main.js and crashed before any app code ran.
- Fix: asar enabled, so app code is a single archive. Files that genuinely
  must be real on disk now ship under resources\ as extraResources:
  shim\ (php.exe is an external process and cannot read inside an asar),
  monaco\ (only monaco-editor/min, the esm tree is excluded), php\, samples\.
- Monaco is loaded by absolute file: URL (encodeURI — install paths contain
  spaces) instead of a relative node_modules path, with a clear toast if the
  editor files are ever missing instead of a silent failure.
- Result: 1,346 files → 76, and the app archive dropped from ~48 MB to ~1 MB.

## 1.4.0 · 2026-07-16 · visible safety net (Desktop\PHP Editor)

- New Desktop\PHP Editor folder holds all safety copies where the user can
  see them: Project Backups\, File Backups\, Changelogs\.
- Project backup on open: a full copy of the project folder (skips junk dirs,
  50 MB/file cap) saved as "<name> — <date>", at most one per day, last 10 kept.
- Rolling file autosave: a snapshot of the working buffer roughly every 20
  edits, alongside the existing pre-save snapshots. Human-readable filenames
  ("2026-07-16 17.42.05.php"), last 40 kept per file. Restore Previous
  Version… reads from the new location.
- Change diary: every visual edit registers a plain-English note (collapsed
  per property, so a slider drag logs once with the final value): "Changed the
  text color of the big heading to #0F6CBD", "Added a button to the page",
  "Swapped the picture…", "Edited the code by hand", "Brought back an older
  version". Notes are appended to Changelogs\<project>.md on save under a
  date + time heading. File ▸ What Did I Change? opens the diary;
  File ▸ Open Backups Folder opens Desktop\PHP Editor.

## 1.3.0 · 2026-07-16 · trust signals + one-click publish (review round 2)

- Safe-editing indicators: every selected element shows a colored pill —
  green "Fully editable", amber "Partly editable", red "Generated by PHP" —
  with a plain-English reason, derived from the instrumenter's per-element
  innerPhp/attrPhp flags. The selection outline in the preview matches the color.
- One-click WordPress publish: "Do it all for me" uploads the plugin (and its
  images/) via FTP into wp-content/plugins/<slug>/, activates it through the
  WordPress REST API (POST /wp/v2/plugins/<id>, Application Password auth,
  done in the main process; password never persisted), and opens the site.
  Falls back to plain instructions if REST activation fails.
- Richer wizard: logo, big top photo (hero with dark overlay), custom button
  text, opening hours, Instagram/Facebook/LinkedIn links, testimonials section.
  Chosen pictures are copied into the project's images/ folder.
- Generated pages keep plain src="images/…" in source (fully editable, green);
  the shortcode rewrites them to plugin_dir_url() at render time. Plugin ZIP
  and both FTP flows now carry the images/ folder along.

## 1.2.1 · 2026-07-16 · installable build

- Added NSIS installer target (PHPStudioSetup.exe) alongside the portable EXE:

## 1.2.0 · 2026-07-15 · layperson-first redesign

- New Home screen at launch with three plain choices: "Edit a page I have",
  "Create a new site page", "Put a page on my website" — plus recent pages.
  The IDE layout is now the "Advanced" mode (toolbar toggle, remembered).
- Simple mode (default): no code tabs, no view switchers, no DOM tree — just
  the page, the properties panel, and Open/Save/Edit Page/Add/Publish.
- Site wizard: answers to a few plain questions (name, tagline, contact,
  sections, color scheme) generate a complete single-file WordPress plugin —
  proper plugin header, versioned changelog block, [name_site] shortcode,
  document-title filter — in Documents\PHP Studio Sites\<name>. All generated
  markup is static HTML inside the shortcode buffer, so every element is
  click-editable in the preview.
- "Install on WordPress": builds a wp-admin-ready ZIP of the plugin (built-in
  store-method ZIP writer, no dependencies) with step-by-step activation
  instructions and a shortcode copy button; or uploads the file via FTP
  directly into wp-content/plugins/<slug>/.
- One-click picture replacement: images get a "Choose picture…" button that
  opens the normal Windows file picker, copies the photo into the project's
  images/ folder, and rewrites the src. PHP-generated images are protected
  with a plain-English explanation.

## 1.1.0 · 2026-07-15 · polish + hardening (external review feedback)

- Flicker-free editing: text/style/attribute changes now patch the live preview
  DOM instantly; source write-back and re-instrumentation happen silently in the
  background. Full reload only for structural changes (add/delete/duplicate/CSS
  rules) or when auto-refresh is off.
- Fixed: editing text of an element containing styling tags (<em>, <span>) no
  longer escapes the tags into visible text — Text box edits inner source as-is.
- Preview server hardening: per-run random session token required on every
  request (query once, then cookie; 403 otherwise); PHP spawned with
  exec/shell_exec/system/passthru/proc_open/popen disabled for preview.
- Automatic backups: a snapshot of the previous file contents is kept on every
  save (last 25, stored outside the project). File ▸ Restore Previous Version…
  loads any snapshot into the editor, undoable, nothing overwritten until Save.
- Publish on save (optional, off by default): saved files upload to the
  configured FTP server in a quiet background queue.
- Source instrumentation moved to a worker thread (UI never blocks on parsing).

## 1.0.0 · 2026-07-15 · first build (PHPStudio.exe)

- Visual PHP website editor for Windows 11, Fluent 2 design, light/dark/auto theme (Mica).
- Live preview runs real PHP (bundled PHP 8.3 portable) through a mini-WordPress shim:
  hooks/filters, shortcodes, escaping, options, wp_head/wp_footer, clean-URL routing.
  Verified against page-drashti-portfolio.php (Astra page template) and pa-site.php
  (shortcode plugin) — both bundled as the sample project.
- Click-to-edit: source instrumenter maps every rendered element back to exact byte
  ranges in the PHP file; edits (text, typography, colors, spacing, layout, attributes,
  CSS rules in-file) are written into the source and are undoable (Ctrl+Z).
- Visual-first UX (per Sunny's feedback): opens in Design view, Edit Page mode on by
  default, plain-English toolbar (Open/Save/Edit Page/Add/Refresh/Publish), code view
  available but tucked behind view toggles.
- Panels: Files/Add/Search, Page Structure (live DOM outline), Properties inspector
  (Figma-style accordions), all resizable/collapsible, layout remembered.
- Drag-and-drop components with drop indicator (Section, Heading, Paragraph, Image,
  Button, Link, Divider, Spacer, 2 Columns, List).
- Device preview (Fill/Desktop/Tablet/Phone), PHP error page + toast, JS error status,
  project-wide search, context menus, toasts, Windows 11-style dialogs.
- FTP/FTPS deploy: test connection, upload current file or whole project with progress.
  Password kept in memory only, never written to disk.
- Monaco code editor (PHP syntax, minimap) for the advanced view.
